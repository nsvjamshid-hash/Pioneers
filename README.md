# Pioneers — o‘rnatish

1. **supabase.com** da bepul loyiha oching.
2. *Authentication → Providers → Email* da **Confirm email** ni o‘chiring.
3. *SQL Editor* ga `schema.sql` ni qo‘yib ishga tushiring.
4. *Authentication → Users → Add user*: email `admin@pioneers.app`, parol `admin52`. **Buni birinchi bo‘lib qiling** — shu email avtomatik admin bo‘ladi. Keyin parolni almashtiring.
5. *Project Settings → API* dan `Project URL` va `anon public` kalitni `config.js` ga yozing.
6. Papkani Vercel ga yuklang (vercel.com → Add New → Project, yoki `npx vercel`). Build kerak emas — oddiy statik sayt.
7. Saytda login: `admin`, parol: `admin52` → pastda “Admin” bo‘limi chiqadi.

Foydalanuvchilar ism/email o‘rniga oddiy login (masalan `ali`) bilan ham ro‘yxatdan o‘ta oladi.
Admin panelda so‘zlarni tahrirlash, o‘zbekcha tarjima va o‘qilishi (rid, vok…) qo‘shish mumkin.
